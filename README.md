# Codex Local Repairs

Personal, HTTP-only delegation for bounded pure-Python repairs. Development in progress; routing is disabled by default. No model is approved or skill installed by this repository.

Requires Python 3.11+ and macOS for isolated candidate execution. No third-party packages.

Run offline checks from this source root:

```sh
python3.11 -B -m unittest discover -s tests -t . -v
```
